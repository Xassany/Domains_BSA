# BSA Projects Overview

This repository contains educational projects on **Business Analysis** and **System Analysis**, completed as part of a sequential study of system and business analysis stages.

The projects cover practical cases related to:
- online barbershop booking,
- order delivery,
- requirements modeling,
- business process modeling,
- data modeling,
- user scenarios and use cases.

Each module reflects a specific stage of analytical work and includes corresponding artifacts.

---

## What's Inside

### Project 1: Online Barbershop Booking
This project focuses on the analysis of an online booking system for barbershop services.

Key areas covered:
- Use Cases,
- Swimlane diagrams,
- CRUD operations,
- State transition models,
- User stories,
- Business processes,
- Roles and stakeholder interactions.

### Project 2: Order Delivery
This project analyzes an order delivery system involving operators, couriers, dispatchers, administrators, and accounting.

Key areas covered:
- Business processes,
- Role participation,
- Data lifecycle,
- User scenarios,
- Use cases,
- External systems integration.
