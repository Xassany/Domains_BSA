# BSA Projects Overview

Репозиторий содержит учебные проекты по **Business Analysis** и **System Analysis**, выполненные в рамках последовательного изучения этапов системного и бизнес-анализа.

В проектах рассматриваются практические кейсы, связанные с:
- онлайн-записью в барбершоп,
- доставкой заказов,
- моделированием требований,
- бизнес-процессов,
- данных,
- пользовательских сценариев и вариантов использования.

Каждый модуль отражает отдельный этап аналитической работы и включает соответствующие артефакты.

---

## Что внутри

### Проект 1: Онлайн-запись в барбершоп
Проект посвящён анализу системы онлайн-записи клиентов на услуги барбершопа.

В рамках проекта были проработаны:
- пользовательские сценарии (Use Cases),
- Swimlane-диаграммы,
- CRUD-операции,
- статусные модели,
- пользовательские истории,
- бизнес-процессы,
- роли и взаимодействия участников.

### Проект 2: Доставка заказов
Проект посвящён анализу системы доставки заказов с участием операторов, курьеров, диспетчеров, администраторов и бухгалтерии.

В рамках проекта были проработаны:
- бизнес-процессы,
- участие ролей,
- жизненный цикл данных,
- пользовательские сценарии,
- варианты использования,
- взаимодействие с внешними системами.

### BSA10 — Проектирование функциональных требований

**Артефакты:**

**Артефакты:**
- Product presentation form (Форма представления продукта)
- Key user scenarios (Ключевые сценарии)
- Screen form list (Список экранных форм)
- Wireframes (Макеты экранных форм)
- Controls description (Описание контролей)

### BSA12 — Нефункциональные требования
**Выполнено:**
- Определение и классификация нефункциональных требований (НФТ)
- Выбор типов НФТ (доступность, надежность, масштабируемость, безопасность и др.)
- Описание атрибутов производительности (время отклика, пиковые нагрузки)
- Определение атрибутов доступности, надежности и масштабирования
- Определение атрибутов безопасности (парольная политика, многофакторная аутентификация, логирование)

**Артефакты:**
- Non-functional requirements list (Список НФТ)
- Performance attributes (Атрибуты производительности)
- Security, availability and reliability requirements (Требования к безопасности, доступности и надежности)

### BSA13 — Управление требованиями, качеством, задачами
**Выполнено:**
- Выделение типов требований, определение их атрибутов и статусов
- Создание и регистрация требований в системе управления задачами
- Разработка кейсов позитивного и негативного тестирования

**Артефакты:**

- Defect reports (Отчеты о дефектах / баг-репорты)

### BSA14 — Интеграция ИТ-систем
**Выполнено:**
- Выделение потоков данных для интеграции
- Определение мастер-систем и систем-получателей
- Формирование словаря данных для интеграционных потоков
- Описание сценариев интеграции
- Определение требований к объему, количеству, частоте и срокам передачи данных

**Артефакты:**
- Data flow list (Список потоков данных)
- Integration data dictionary (Словарь данных интеграции)
- Integration scenarios (Сценарии интеграции)
- Integration requirements (Требования к потокам данных)

---

### BSA15 — Интеграция веб-сервисами REST
**Выполнено:**
- Определение и описание HTTP-методов для взаимодействия систем по REST
- Актуализация Use Cases с учетом интеграционного взаимодействия и справочников
- Описание элементов тела запросов и ответов
- Выполнение маппинга данных между системой-отправителем и системой-получателем
- Описание требований к обработке возможных ошибок интеграции

**Артефакты:**
- REST API methods description (Описание методов интеграции)
- Request/Response parameters (Описание параметров запроса/ответа)
- Data mapping table (Таблица маппинга данных)
- Error handling requirements (Описание обработки ошибок)

---

### BSA16 — Интеграция веб-сервисами SOAP
**Выполнено:**
- Анализ WSDL-документов и структуры XML
- Определение методов веб-сервисов, описанных в разделе portType
- Обратное проектирование требований к разработке на основе WSDL-описаний
- Описание форматов входных (input) и выходных (output) сообщений
- Определение endpoint (адресов) для веб-сервисов

**Артефакты:**
- WSDL analysis (Анализ тегов и разделов WSDL)
- Reverse-engineered requirements (Требования к разработке на основе обратного проектирования)
- SOAP messages description (Описание форматов сообщений)
